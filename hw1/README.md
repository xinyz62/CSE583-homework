Process
I used pandas to read the Fremont Bridge bicycle data. I added the total count, hour, and year, and selected the data from 2016. I checked for missing data and removed one missing time point. Then I calculated the average bicycle count for each hour and used matplotlib to make the plot. I also used pandas to find the busiest hour.

AI Assistance
I used AI assistance for a few more complicated parts, such as checking missing data and using groupby() to calculate the average bicycle count by hour. I also sometimes used AI to quickly remind me of some commands, such as plotting commands in matplotlib.pyplot.

Bonus
I converted the Date column to datetime. Python datetime is useful for dates and times, while pandas datetime is useful for dataframe data and makes it easy to get the hour and year.
